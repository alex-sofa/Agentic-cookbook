# Recipe template

Copy this into a new file inside the matching chapter folder and add it to `SUMMARY.md`.

```markdown
# <Short title>

**Problem:** One or two sentences.

**Solution:** One or two sentences with the recommended approach.

## Steps

1. …
2. …

## Notes

- Pitfalls, alternatives, when not to use this.

## References

- [Title](URL)
```

Keep recipes to about one screen. Split if longer.
